# prowl-web

Marketing landing page for [Prowl](https://github.com/prowl-tools/prowl), built with Next.js 16 + Tailwind CSS.

Live at [prowl.tools](https://prowl.tools).

## Development

```bash
npm install
npm run dev
```

## Prowl Hunts

```bash
npm run prowl:install-browsers
npx prowl run hello
```

## Build

```bash
npm run build
```
